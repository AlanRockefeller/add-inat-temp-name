# Changelog

## 0.2 - 2026-10-21

- Batch mode: click the toolbar icon to open a page where you paste observation numbers, observation
  URLs or observation search URLs. It lists every provisional name found, checks each one, and steps
  through creating the selected names.
- Optional **Create automatically** setting (off by default) that saves every selected name without
  reviewing each form. It reports each name as created or failed, with iNaturalist's error message.
- The change comment lists every observation that has the name, plus every phylogenetic tree URL.
